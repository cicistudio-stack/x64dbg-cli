# x64dbg-cli command reference

Generated by `python src/cli/tests/gen_docs.py` from the `help` op of the built `x64dbg-cli.exe` (80 ops), the schema files
in `src/cli/schema` and the notes kept in that script. `--check` fails when this file is out of date.

Every op is also available in text mode as `!op args` (first positional token = main argument, other keys as `--key value`, 
see README). Request options (`timeout_ms`, `wait`, `on_timeout`, `max_output`, ...) are top-level request fields, never keys of `args`.
Schema notation: `?` optional key, `(a|b)` alternatives, `addr` = `"0x" + 16 lowercase hex digits`, `u32` = `"0x" + 8 hex digits`,
`hex` = lowercase hex bytes, `table` = captured reference table (see README).

## Session and utility

### status

Debugger state, process info, last event, CLI info. Answered out of band (also while another request waits).

* Precondition: `any` (`any` = no session needed, `debugging` = a session exists, `paused` = registers are readable). Milestone M1.
* Text form: `!status`

```
args: {}
data: {process:(null|{path:str, name:str, base:addr, entry:(addr|null)}), csp:(addr|null),
       last_exception:(null|{code:addr, name:(str|null), address:addr, first_chance:bool}),
       last_event:(null|{seq:int, type:str}),
       time_wasted_ms:int, engine:str, userdir:str, cli:{version:str, protocol:int}, ref_progress:(null|int)}
```

### help

Lists the ops, or the usage of one op.

* Precondition: `any` (`any` = no session needed, `debugging` = a session exists, `paused` = registers are readable). Milestone M1.
* Text form: `!help [topic]`

```
args: {topic?:str}
data: {ops:[{name:str, milestone:enum(M1|M2|M3|M4), precondition:enum(any|debugging|paused), usage:str}]}
```
